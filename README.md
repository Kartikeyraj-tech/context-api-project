# KK's Login App

A simple React app with a login form. After you submit a username and password, the app shows "Welcome, username". Until then, it shows "Please Login". User data is shared across components using React Context.

Made by KK. Built for practice with React state, Context, and CSS.

## Features

- Username and password form
- Global user state with React Context API
- Conditional rendering: "Please Login" before login, "Welcome, username" after login
- Background image with a black fallback color

## Tech Stack

- React
- Vite
- CSS
- React Context API (`useState`, `useContext`)
